Built for Performance, Security & Simplicity

Everything you need to connect to FortiGate VPNs smoothly on any Linux desktop.

Privilege Separation Architecture

The GUI runs completely unprivileged in user space. Privileged IPsec tunnel and routing operations are handled by an elevated Rust helper binary via native Polkit (`pkexec`).

Hardware & OS Keyring Storage

Pre-Shared Keys (PSK) and account passwords are saved directly into the Linux OS Keyring (`libsecret` / Gnome Keyring / KWallet) with restricted `0600` file fallbacks.

Interactive 2FA / Email OTP

Seamlessly intercepts FortiGate `XAUTH_PASSCODE` prompts inside a POSIX PTY (`libc::posix_openpt`) and provides a clean email verification code entry modal.

System Tray Live Dropdown

Displays live status (🟢/🔴) and kernel XFRM IPsec traffic throughput (`1.25 MB ↓ • 340 KB ↑`) directly in the tray dropdown. Closing the window hides to tray.

Auto-Reconnect & Single Instance

Optionally re-establishes dropped tunnels automatically after 3 seconds. Built-in single-instance lock prevents duplicate process execution.

Universal Linux Installers

Automated scripts (`./install.sh`) for Arch Linux / Omarchy, Ubuntu / Debian, Fedora / RHEL, and openSUSE with desktop shortcuts and Polkit setup.

Quick Multi-Distro Installation

Run the auto-detecting installer or select your Linux distribution family.

# Clone repository and run auto-detecting universal installer
git clone https://github.com/JPHultra/findmore-vpn.git
cd findmore-vpn
./install.sh
